# Bundled fonts

Plus Jakarta Sans (normal variable, 200–800) and Cormorant Garamond (normal variable, 300–700), Latin WOFF2 files from the official Google Fonts CSS distribution, downloaded 2026-11-09. Source families: https://github.com/google/fonts/tree/main/ofl/plusjakartasans and https://github.com/google/fonts/tree/main/ofl/cormorantgaramond . Family-specific SIL Open Font Licenses are included alongside the assets.

Loaded with next/font/local so production builds require no Google Fonts requests. The same display/sans CSS variables are retained.
